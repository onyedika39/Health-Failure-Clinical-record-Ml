# Heart Failure Clinical Records Machine Learning

Machine learning notebook analyzing heart failure clinical records to identify risk factors and predict patient outcomes.

## Objective

This project is organized as a portfolio case study to show the full analysis workflow: understanding the business problem, preparing the data, exploring patterns, building the final output, and communicating insights clearly.

## Business Questions

- Which clinical features are associated with patient outcomes?
- How can machine learning support risk prediction?
- What insights can improve understanding of heart failure records?

## Tools Used

- Python
- Jupyter Notebook
- pandas
- scikit-learn
- Healthcare analytics
- Classification modeling
